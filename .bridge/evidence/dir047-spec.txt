## 1. Executive Mandate & SWOT Governance Framework
This directive establishes the ultimate, all-encompassing User Acceptance Testing (UAT) and release certification framework for ResumePilotAI (IME365). 

To ensure complete production resilience, UAT is systematically governed by a rigorous **SWOT Architecture Matrix**:
- **Strengths (S):** Protect and verify all 28 certified baseline modules (51 resume templates, dual-database sync, ATS pipeline, AI interview coach, Cuba M3 design system) with zero-diff preservation.
- **Weaknesses (W):** Systematically detect and eliminate vulnerabilities (locale key drift across 15 languages, simulated latency, DOM unmount style leaks, unlayered CSS overrides).
- **Opportunities (O):** Deploy automated multi-viewport Playwright crawls, pure Node.js visual pixel diffing (bridge visual-diff), in-page getBoundingClientRect() collision probes, and unified 4-portal customer journeys.
- **Threats (T):** Adversarial penetration tests against multi-tenant data leakage, plaintext secret exposure, XSS injection, dark-mode contrast inversions, and WCAG accessibility violations.
